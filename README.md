# ①課題名
エンディングノート

## ②課題内容（どんな作品か）
- おひとりさま向けエンディングノート。
- 人生のログを記録し、いざというときにそのログの続きを引き受けてもらう人を指定。一定条件下で、引受人が情報を閲覧でき、しかるべき対処ができる仕組み。
- 自分の人生を定期的に棚卸し、周囲とのつながりや絆を再確認することを目指す。

## ③アプリのデプロイURL
https://gs-aiko.sakura.ne.jp/kadai09/index.php

## ④アプリのログイン用IDまたはPassword（ある場合）
テスト用IDを設定済み

## ⑤工夫した点・こだわった点
- 項目ごとに入力方式や入力したい件数が異なるので、DBの指定を工夫した。
- 本人と引受人というステータスの異なるユーザー登録ができるようにした。
- 現状のサイトはテスト用ユーザーを事前にDBに登録してあり、新規登録はできない仕様になっている。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- いろいろと不具合が見つかっており、時間内にすべて対応できないので、順次直していきたい。
- 項目設定が難しかった！！
